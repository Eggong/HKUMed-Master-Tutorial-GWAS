# HKUMed Master Tutorial: Genome-Wide Association Studies

This repository hosts teaching materials for an introductory practical tutorial on **genome-wide association studies (GWAS)** for Master’s students at HKUMed.

The tutorial introduces the basic workflow of GWAS analysis, including genotype quality control, population structure assessment, and association testing using commonly used bioinformatics tools.

## Tutorial title

**Introduction to Genome-Wide Association Studies**

## Audience

This tutorial is designed for **Master’s students** who are new to GWAS and genetic association analysis.

No advanced prior experience in statistical genetics is required, but basic familiarity with command-line operations and R will be helpful.

## Suggested duration

The tutorial is designed for approximately:

**Three practical sessions**

## Software requirements

Participants are expected to use the following software:

- **PLINK 1.9**
- **R**
- **Bash terminal**

Depending on the teaching environment, these tools may be available on a local computer, remote server, or teaching cluster.
